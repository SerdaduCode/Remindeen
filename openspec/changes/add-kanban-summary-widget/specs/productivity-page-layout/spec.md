## ADDED Requirements

### Requirement: Summary row beneath the Kanban panel
Page 2 (the Productivity view) SHALL render a compact summary row directly beneath the Kanban panel, containing the Kanban Summary widget alongside any other compact widgets placed in that same row.

#### Scenario: Viewing the Kanban column
- **WHEN** a signed-in user views the Productivity page
- **THEN** a summary row appears beneath the Kanban board, showing the Kanban Summary widget
